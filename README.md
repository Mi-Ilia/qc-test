# Трекер привычек

Простое и современное веб-приложение для отслеживания привычек. Работает полностью в браузере без сервера.

![Скринш приложения](./screenshot.png)

## Возможности

- ✅ **Добавление привычек** — создавайте привычки с названием, иконкой и цветом
- ✅ **Еженедельный трекер** — отмечайте выполнение привычек по дням недели
- ✅ **Панель прогресса** — отслеживайте ежедневный и недельный прогресс
- ✅ **Тёмная тема** — переключайтесь между светлой и тёмной темой
- ✅ **Сохранение данных** — все данные хранятся в localStorage браузера
- ✅ **Экспорт/импорт** — создавайте резервные копии данных в формате JSON
- ✅ **Адаптивный дизайн** — работает на компьютерах и мобильных устройствах
- ✅ **Русский интерфейс** — полностью локализованный интерфейс

## Быстрый старт

### Локальный запуск

1. Скачайте или клонируйте файлы проекта в локальную папку
2. Откройте файл `index.html` в любом современном браузере

Или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен)
npx serve .
```

Затем откройте в браузере `http://localhost:8000`

## Развёртывание на GitHub Pages

1. **Создайте репозиторий на GitHub**
   - Перейдите на https://github.com
   - Нажмите "New repository"
   - Введите имя репозитория (например, `habit-tracker`)
   - Создайте репозиторий

2. **Загрузите файлы проекта**
   
   Вариант A — через веб-интерфейс:
   - Нажмите "Upload files"
   - Перетащите все файлы проекта (`index.html`, `style.css`, `app.js`, `README.md`, `.gitignore`)
   - Нажмите "Commit changes"

   Вариант B — через Git:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/habit-tracker.git
   git push -u origin main
   ```

3. **Настройте GitHub Pages**
   - Откройте вкладку **Settings** вашего репозитория
   - В левом меню выберите **Pages**
   - В разделе "Build and deployment":
     - Source: выберите **Deploy from a branch**
     - Branch: выберите **main** и папку **/(root)**
   - Нажмите **Save**

4. **Дождитесь публикации**
   - Через 1-2 минуты ваш сайт будет доступен по адресу:
   - `https://ВАШ_НИК.github.io/habit-tracker/`

## Как пользоваться

### Добавление привычки

1. Введите название привычки в поле "Название привычки"
2. Выберите иконку из предложенных вариантов
3. Выберите цвет для привычки
4. Нажмите кнопку "Добавить привычку"

### Отметка выполнения

- Кликните на ячейку соответствующего дня, чтобы отметить привычку как выполненную
- Повторный клик отменит отметку
- Выполненные ячейки окрашиваются в цвет привычки с галочкой

### Навигация по неделям

- Используйте стрелки ← и → для перехода к предыдущей/следующей неделе
- Кнопка "Сегодня" возвращает к текущей неделе
- Сегодняшний день выделен фоном

### Редактирование и удаление

- Наведите курсор на привычку в таблице
- Нажмите кнопку ✏️ для редактирования
- Нажмите кнопку 🗑️ для удаления (требуется подтверждение)

### Экспорт и импорт данных

**Экспорт:**
1. Нажмите кнопку "Экспорт данных"
2. Файл резервной копии скачается автоматически

**Импорт:**
1. Нажмите кнопку "Импорт данных"
2. Выберите ранее экспортированный JSON-файл
3. Подтвердите замену текущих данных

## Хранение данных

⚠️ **Важно!** Все данные хранятся только в вашем браузере (localStorage).

- Данные не передаются на сервер
- Очистка данных браузера удалит все привычки
- Регулярно делайте экспорт резервных копий
- Резервные копии можно импортировать в любом браузере
